# GameMaker Rules

- Project uses modern GameMaker
- Primary language is GML
- Preserve existing .yy formatting
- Never alter GUIDs unless explicitly requested
- Never rename resources automatically
- Use modern GML syntax
- Preserve object event structures
- Keep inheritance intact unless requested
- Avoid unnecessary formatting changes
- Preserve room structure and layers
- Modify only necessary fields in .yy files
- Prefer scripts/functions over duplicated object code
- Keep naming conventions consistent
- Avoid changing sprite origins unless requested
- Keep compatibility with current runtime
